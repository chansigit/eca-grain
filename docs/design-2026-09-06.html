Metacell 方案：一条命令跑到底，把细胞打包成小组

给 eca-rsi 已经发布的每个组织（release/final.h5ad）做 metacell，供后面算 GRN 用。 2026-09-06 讨论定稿，实现还没开始。

一句话：把表达很像的细胞，二十个左右打包成一个"小组"，把它们的 counts 加起来，当作一个更干净的细胞来用。 打包时不能把不同状态的细胞混在一起，混进来的孤立细胞要挑出去，稀有细胞不能弄丢，小组数量还要和原来的细胞数大致成比例。 整个过程参数事先定死，一条命令跑完，不回头调。

四条原则

一条命令跑到底参数事先定死，中间没有人工检查点，不看结果回头调参。诊断只进报告，不进流程。
一个细胞都不丢账细胞可以不进小组，但每个细胞在表里都有一行、有去向、有原因。
只拆不合、不重洗牌复查只在原小组内部细化，已通过的小组一个不动。
确定性固定随机种子，同样输入同样结果。
"不丢账"是本方案的约定，不是所有 metacell 算法的共性。 MetaCells 2 会把 outlier 放进一个未分配桶；mcRigor 的默认用法是把可疑小组整个剔除；SuperCell 和 SEACells 全部分配、没有任何丢弃选项。 这里借 MetaCells 2 的 outlier 思路，但把"丢"改成"单独记账"。

整体流程

① 打包

SuperCell 算法
  • 按样本、再按粗标签分格子
  • 按粗标签跨样本重算坐标
  • 格子内最近的约 20 个打成一组
  • 保留层次树
→

② 挑 outlier

MetaCells 2 规则
  • 每个细胞和所在小组比
  • 差太多的挑出来
  • 不进小组，单独记账
  • 每格子最多挑 25%
→

③ 体检

mcRigor
  • 查小组内部是不是"一家人"
  • 不看标签
  • 结论：可信 / 可疑
→

④ 复查

树上多切一刀
  • 可疑小组一分为二
  • 再体检一次
  • 最小 10 个就停
  • 可信小组不动
→

⑤ 交付

每组织一套表
  • 细胞去向表
  • 小组 counts 矩阵
  • 阈值、汇总、报告
交付前的守恒检查：所有小组的 size 加上 outlier 数，必须正好等于原始细胞数，每个格子也一样。 对不上就算失败，不写输出。这是整个流程唯二的失败条件之一，另一个是输入缺失。

① 打包：怎么分小组

  1. 先分格子：每个样本一格，格子里再按细标签分。 样本 A 的 naive T 细胞是一格，样本 A 的 memory T 细胞是另一格。小组永远不跨样本、不跨标签。 不跨样本是为了保住每个样本各自的细胞组成，也避开 Harmony 校正把不同样本的状态硬拉到一起。 不跨标签是把已有标注当成不能越过的边界（一开始设计用粗标签，后来定为细标签；粗标签作为核对列记录）。 代价：多样本数据里小标签会被切成很多小格子，不到 20 个细胞的格子整格一个小组，甚至单细胞。
  2. 每一类细胞重新"看清楚"，坐标跨样本算，分组只在格子里做。 全局 PCA 的前几十个方向都在描述 T 细胞和 B 细胞的差别，T 细胞内部 naive 和 memory 那点差异根本不在里面，所以要按类型重算坐标。 但格子可能很小，样本 A 只有 30 个巨噬细胞，30 个细胞算不出像样的 PCA。办法是把"坐标从哪来"和"谁能分到一组"分开： 坐标在整个组织的全部巨噬细胞上算（几百上千个，稳定），选高变基因时只留在样本内部也高变的基因，批次专属基因自动出局； 分组时那 30 个细胞只借用这套坐标，只和自己格子里的细胞连边。批次偏移在一个格子内是常数，不改变格子里谁和谁近。 如果整个组织这一类细胞合起来还不到 100 个，就不重算，直接用 final.h5ad 里现成的全局坐标。 选高变基因时用固定名单剔掉细胞周期和解离应激基因，免得小组按"分裂期 / 静止期"分组。这和 ZMIP 按 lineage 跨样本重嵌入是同一做法。
  3. 把最近的约 20 个细胞打成一组。 在近邻图上做 walktrap 社区切分，小组数 = 格子数 ÷ 20 四舍五入（至少 1 组）。γ = 20 是目标平均值，不是固定大小： 70 个细胞切 4 组，各组多大由树决定，比如 25 / 22 / 15 / 8，不是 20 / 20 / 20 / 10。比例只需要小组数跟着细胞数走，这一条在每个格子里都成立；大小不均只影响每组的噪声，报告里给大小分布。组内细胞互为最近邻， naive 和 memory 自然落到各自的组里，不需要标签告诉它。这和随机分组完全不同：随机分每组都是混合物，这里每组接近单一状态。 切分的层次树整棵留着，复查时直接往下切，不用重新聚类。
  4. 小格子照样保留。 格子里不到 20 个细胞，整格算一个小组，根本不需要坐标；只有三五个也算一个小组。不并到别的格子里去。 格子在 20 到几十个之间时，近邻数和 PCA 维数跟着规模缩：近邻数取 min(15, 格子数 − 1)，PCA 维数取 min(30, 该类合并数 / 5)。

② 挑 outlier：谁不该待在小组里

  1. 在小组内部，逐个基因找"断层"。 检验的基因是这一类细胞重算坐标时用的那约 2000 个高变基因（已剔掉细胞周期和应激基因），不是全部基因：状态差异由这些基因定义， 其它基因偶尔爆发一下不该把细胞踢出去。对每个小组的每个检验基因，把组里的细胞按这个基因的表达（按测序深度归一、log2）排个序， 相邻两个值之间如果出现 8 倍以上的断层，断层外侧那几个细胞就在这个基因上"偏离"了；一个断层最多切出 3 个细胞、且不超过小组的 10%。 在任何一个检验基因上偏离的细胞就是 outlier。这是 MetaCells 2 的 gaps 规则，阈值固定，不需要人看，只跑一遍不迭代。
  2. 爆发式表达的基因不算数。 如果某个基因在一个格子里标出了超过 3% 的细胞，说明它是那种时不时爆发一下的基因，不是细胞真的不一样，整个格子忽略它。 MetaCells 2 的那个 3% 就是这个意思：保护基因，不是细胞的门槛。
  3. outlier 不进任何小组，但留在表里，带原因。 它保护两类细胞：漏网的 doublet，以及格子里只有三五个、本来会被硬塞进邻居小组抹掉的稀有状态。后者正是"粗标签模糊化"的真正来源。
  4. 每个格子最多挑 25%。 超过就只取偏离最大的那 25%。这是防止某个格子被挑空、把比例弄歪。挑完之后小组变小也不解散，只在报告里标出，避免 MetaCells 2 那种连锁反应。

MetaCells 2 真正需要人做的是三份名单（排除基因、lateral 基因、noisy 基因）加逐轮审看。这里的处置：排除基因用上游已算好的固定名单；lateral 基因用发表过的固定名单；noisy 基因用表达量下限和 3% 占比规则替代；逐轮审看取消，结果进报告。

③ 体检：mcRigor 在查什么

  1. 查每个小组内部是不是同一种状态。 一家人的基因共表达模式是一致的。如果一个小组里混了 naive 和 memory 两种 T 细胞，基因之间的相关结构会出现异常。 mcRigor 把这个异常程度算出来，和"随机打乱"得到的基线比，超过基线就判可疑。 具体做法：取小组成员在 2000 个高变基因上的表达，算基因两两之间的相关矩阵，量它离"完全不相关"有多远； 再把每个基因在成员之间打乱一遍（相关被破坏、每个基因的分布不变）算同样的量，两者的比值就是这个小组的异质性分数。 基线是把每个细胞的数值在基因之间打乱后算出的同一比值。整套算法在 R 包里不到一百行，这里用 Python 重写，不引入 R。
  2. 它不看标签。 标签粗到只有"T cell"也不影响。粗标签下"标签纯度"永远是 100%，没有信息；要靠这种无标签的检验才能发现打包太粗。
  3. 基线在整个组织上算一次，存下来。 基线随小组大小变化，是一条曲线。按格子算的话小格子里小组太少，曲线不稳，所以按整个组织算。
"可疑"不等于"标错"。 分组时已经不跨标签了，可疑只说明这一组打包太粗、混了同一类型下的不同状态。处理方式是拆细，不是删掉。 outlier 管的是"一个细胞混进了别人家"，体检管的是"一家人其实是两家"，两者互补。

④ 复查：可疑的小组怎么办

  1. 在层次树上往下切一刀。 可疑的小组在打包时留下的 walktrap 子树上一分为二，再体检一次。用的是第 ③ 步存下来的那条基线，不重新算，否则越拆基线越松，标准就漂了。
  2. 最小拆到 10 个就停。 只拆一层，20 最多变成 10。拆到底还不过的，打上 residual_dubious 标记保留，交给下游自己决定用不用。
  3. 可信的小组一个不动，任何细胞不重新洗牌。 和六月 Tabula Sapiens 那套"把所有可疑细胞倒在一起重新分"不同，这里只拆不合。原来的分组完整保留，父子关系可追溯，小组数量最多只涨一倍，还只涨可疑的那部分。

小组数量大致跟着细胞数走。 固定 γ 就保证了这一点；复查最多让可疑部分翻倍，outlier 每格子封顶 25%，整体偏差压在百分之十几以内。不做"每类各 50 个"那种平衡， 因为下游 GRN 工具（GRNBoost2、pySCENIC）不接受权重，比例一旦在这里弄歪，后面救不回来。
任何时候都能精确还原。 每个小组带 size，outlier 有计数。想知道某个样本里 T 细胞占多少，把 T 细胞小组的 size 加上 T 细胞 outlier 数就是 10000，一个不差。

顺带一句：这些小组不是生物学重复。500 个 T 细胞小组来自同一个样本，是同一份样本内部的 500 个采样点。跨条件比较时，重复的单位仍然是样本。

和六月 Tabula Sapiens 方案的区别

六月那套是 SuperCell 2.0 加 mcRigor，可疑的细胞全部倒在一起按 γ = 10、5、3 重新分。它证明了两件事：单一 γ 会系统性冤枉上皮、分泌、稀有类型； 变粒度补救后保留率能从七成拉到 97% 以上。这次沿用这两条教训，加上 outlier 一步，把补救改成"树上原地切一刀、只切一层"， 目的是把小组数量的膨胀控制住，让比例大致对上，而且全程不需要人插手。
